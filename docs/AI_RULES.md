# Правила ИИ для NEXUS PORTAL
1. Прочитать docs/GDD.md и docs/WORK_PLAN.md полностью.
2. Никаких платных AI API. Внешние ИИ работают по копируемым промптам.
3. Не трогать другие сервисы VPS, не хранить секреты в GitHub, логах и чате.
4. Каждая задача: отдельная ветка, зона файлов, PR, зелёный обязательный CI.
5. После зелёного CI автоматический merge только при актуальном SHA и разрешении проекта.
6. Релизы только из релизного workflow; проверка артефакта и откат.
7. Не требовать скриншотов и повторных ручных проверок.
8. Новые функции писать тестируемо, не ломать существующие.
9. Решения, принятые исполнителем без владельца, фиксировать в docs/ARCHITECTURE.md.
