# NEXUS PORTAL

Универсальный портал управления разработкой без платных ИИ API.

Проектирование: `docs/GDD.md`. План реализации: `docs/WORK_PLAN.md`.

Портал генерирует обучающий промпт и файлы репозитория, управляет задачами, GitHub CI/PR, памятью, релизами и разрешённым SSH-деплоем.

**Статус:** разработка. Не развёрнут на VPS.

## NEXUS Project Blueprint

Работающий изолированный модуль утверждённых JSON-планов: схема, импорт и версии,
DAG-очередь, безопасная выдача промптов, отдельное состояние и ручная приёмка.
Запуск, интеграция и API: [docs/BLUEPRINT.md](docs/BLUEPRINT.md).
